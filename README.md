# resilient_claim_coupon_backend

## Project name
resilient_claim_coupon_backend

## Year
2026

## Purpose
Personal 2026 project.

## Features
- Click tracking (`GET /track/:linkId`) with always-on redirect and async click logging
- Coupon claim endpoints with durable claim records
- Order creation with webhook delivery and retry helpers
- PostgreSQL persistence via `pg`
- Environment-based configuration with dotenv
- Node.js + Express 5

## Tech Stack used
- Express
- PostgreSQL
- Axios
